# src/frontend — Interfaz de usuario

La UI. Framework definido en la constitución (`spec/constitution/03_stack`).

| Carpeta | Rol |
|---|---|
| `app/` | Entrada/arranque y ruteo de la app. |
| `views/` | Pantallas/páginas completas. |
| `components/` | Componentes reutilizables. |
| `layout/` | Estructura visual compartida (headers, shells, grids). |
| `state/` | Estado de la aplicación (stores). |
| `services/` | Cliente de la API y utilidades de datos del front. |
| `visuals/` | Recursos estáticos: assets, iconos, imágenes, temas. |
