# docs/audit — Auditoría y cumplimiento

Notas y evidencias de auditoría: revisiones de seguridad, cumplimiento normativo, y el registro
de aplicaciones de la **regla de dos aprobadores** (cambios a RLS/audit). El *mecanismo* de auditoría
en DB (audit_log, governance_registry) se diseña en `docs/architecture/gobernanza-db.md`.
