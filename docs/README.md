# docs/ — Cómo y por qué quedó así (descriptivo)

Documenta la **realidad construida**. Si los `docs/` no coinciden con el código, **los docs están mal**
(al revés que `spec/`, que es prescriptivo).

| Carpeta | Contiene |
|---|---|
| `decisions/` | ADRs (Architecture Decision Records): decisiones no triviales y su porqué. |
| `AutoCV-legacy/` | El primer intento (referencia) + su **diagnóstico honesto** de qué salió mal. |
| `assets/` | Imágenes del README (previews del CV). |
